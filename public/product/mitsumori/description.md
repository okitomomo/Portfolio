# 機能紹介

## 見積書作成機能

- 登録された商品から明細を入力していくことで、最終的な見積金額の合計を計算します
    - 今回限りの商品は手入力できます（出精値引きなど）
    - 数量や単価の変更時、合計金額が自動で再計算されます
- 見積書を `xlsx` 形式および `pdf` 形式で出力することができます
    - 見積書を出力すると見積情報の編集がロックされます
    - 再編集する場合は、編集前の見積を旧バージョンとしてバージョン管理します
- 過去の見積書を複製することができます

## 請求書作成機能

- 請求書を `xlsx` 形式および `pdf` 形式で出力することができます
    - 2パターンで出力することができます
        - 一括：見積書の明細を隠して、「一式」として一括の請求書を作成する
        - 明細：見積書の明細の通りの請求書を作成する
    - 請求書出力後も、見積編集に遡り編集することができます

## マスタメンテ機能

- 商品マスタをカテゴリに分けてメンテナンスすることができます
    - 商品ごとに、期間ごとの価格を設定することができます
